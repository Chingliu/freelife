# A股技术分析学习系统（tdx-tq-analyzer）

本学习系统的正式交付物是**一份行情与教学合一的离线 HTML**：`report_<CODE>.html`。不再要求用户分别打开投资分析报告和 `learning_report.html`。

## 六章教学结构

1. K线基础：四价、实体、影线、形态与位置。
2. 成交量：成交量/成交额、均量、量比、放量缩量及ETF成交特性。
3. 趋势分析：高低点结构、移动平均线、趋势延续与失效。
4. 日K/周K/月K：日线聚合周线/月线，自上而下处理周期冲突。
5. 技术指标：RSI、MACD、BOLL、ATR的计算来源、读法和局限。
6. 量价综合：结合周期、趋势、价位、成交量和指标形成可证伪的研究判断。

每章均包含学习目标、原理/公式、由本次真实 TQ 日线计算的 510330 案例、逐步分析方法、常见误判和本章练习及答案解析。

## 运行

```bash
python scripts/run_analysis.py 510330 --outdir C:/reports
```

流程为 TQ 采集 → `analyze.py` → `build_report.py`，最终只生成 `report_510330_SH.html` 作为完整报告，同时保留 raw/metrics/chart JSON 供复核。HTML 图表、课程和练习均内嵌，不依赖 CDN 或网络。

## 真实数据与周期边界

- 日K案例来自 TQ 实际返回的日线，不使用虚构价格或K线。
- 周K/月K由已采集日K按 OHLCV 规则聚合：开盘取首日、收盘取末日、最高取最大值、最低取最小值、成交量求和。
- 周/月聚合只覆盖本次实际采集窗口；样本较少时，报告展示样本数量和覆盖日期，不据此宣称掌握长期牛熊结构。
- 指标由日线OHLC计算，报告展示参数与最新值；指标是历史数据的派生量，不是独立预测信号。
- 若缺少真实日线数组，课程区会明确提示重新采集，不会用示例数字冒充真实行情。

## 进度工具

`learning_engine.py` 与 `learning_report.py` 暂保留为实验性进度工具，但不属于正式报告产出链路；正式行情报告不会再生成第二份学习报告。
