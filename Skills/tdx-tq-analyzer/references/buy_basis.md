# 买入依据框架（研究观察）

## 设计来源：从 Cursor 规则中吸收了什么

本框架的素材来自 `D:\freelife\.cursor\rules\{etf-research-platform,stock-selection-platform}.mdc`。经核查，该规则库的事实锚点（MCP 工具、文档、实现目录、数据状态）真实存在，但部分机制存在缺陷。**只吸收可论证成立的部分**：

| 吸收的要素 | 为什么可论证成立 |
|---|---|
| 否决优先于多数票 | 趋势与资金同时转空时，"多数维度支持"不能覆盖硬风险；这是风控常识，不依赖任何回测 |
| 触发 / 止损 / 观察点三元组 | 让结论可执行且可证伪；即使当前档位为观望，也必须写"若未来成立"的条件 |
| 位置与风险回报核对、偏离过大写等待条件 | 避免在压力位追高；R:R 以近 20 日高低点作**粗估代理**并明确标注，不伪装成精确目标 |
| 量能必评、无数据写"未评估" | 成交量是 TQ 可得字段，必须核对；缺失时不得编造 |
| 消息面 / 筹码结构默认"未评估" | TQ 无新闻检索、无筹码字段；宽基 ETF 通常也无个股筹码概念。不得声称"无利空" |
| 证据等级需有质量门槛 | 原平台把 Sharpe -0.01、MDD 43% 的策略评为 B 级（只看 OOS Calmar>0），是虚假严谨。本框架直接封顶 C |

**明确弃用**：
- 原平台的 `缩圈→否决→共振→定仓` 四步 + `preferred/avoid/Calmar Top3/vol_target` 决策链 —— 依赖 `research_*` 回测引擎，本技能不接入，不得冒充。
- `alwaysApply: true`、强制 Canvas、聊天只给 2–4 句 —— 环境相关且损害信息交付。
- "OOS pass 或证据≥B 即可风险开启" —— 1 年样本外 + Calmar>0 的门槛过松，不采纳。
- 任何"推荐买入"口吻。

## 本框架的数据边界

输入只有 TQ 返回的：实时快照（价、内外盘、委比、IOPV）、近 105 个交易日日线、若干 `more_info` 字段。因此：

- **不做样本外回测、不做跨标的泛化、不做消息面检索**。证据等级上限为 **C**；触发硬否决时降为 **D**。
- 每个数值必须可追溯到 TQ 字段或由日线计算得出；支撑/压力取近 20 日实际高低点，不臆造。
- 输出永远是"研究观察"，不是买入建议、不是自动交易指令。

## 判定规则（`analyze.py::buycase`）

先检查硬否决（任一触发 → 档位"不成立（否决）"、等级 D）：

1. 趋势位置 = 不支持 **且** 资金确认 = 不支持 —— 价格同时位于 MA20/MA60 下方且 CMF20 < -0.05。
2. 位置偏贵（贴近近 20 日高点、R:R < 1）**且** 量能结构不支持 —— 放量滞涨/缩量。
3. 可用日线不足 60 根，无法计算 MA60 与 20 日 CMF。

然后按四维核对（趋势位置 / 量能确认 / 资金确认 / 位置与风险回报），每维取值：`支持` / `中性` / `不支持` / `未评估`。消息面与筹码结构固定为"未评估"。

档位：无否决且 3 维支持 + 位置合理 → 关注；≥2 维支持 → 试探；其余 → 观望。

## 报告中的呈现

HTML 报告新增独立章节「买入依据核对（研究观察，非买入建议）」，包含：
- 档位 / 证据等级 / 硬否决数量 三项 KPI
- 否决状态横幅（绿色"未触发"或红色列出具体否决项）
- 六维核对表（含每项的数据依据）
- 触发 / 止损 / 观察点三元组表
- 边界声明与固定免责声明

## 口径提醒

- 内外盘、CMF 是统计推断，不等同真实主力账户进出；宽基 ETF 的巨额成交常含一级申赎与做市商对冲。
- R:R 用近 20 日高低点作代理，只是粗估；不构成目标价。
- 盘中运行时，最后一根日线是未收盘的当日值，量比会被低估——报告已标注"盘中快照"。
